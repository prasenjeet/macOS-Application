The Art of Code

How software shapes the modern world — one function at a time.

Code is the language of machines, but the best code is written for humans. The machine will faithfully execute whatever you write; it's your fellow developers — and your future self — who need to understand it.

Elegance in Simplicity

Consider a simple Swift function that reads HTML files from the Desktop:

func scanDesktop() -> [HTMLFile] {
    guard let desktop = FileManager.default
        .urls(for: .desktopDirectory, in: .userDomainMask)
        .first else { return [] }

    return (try? FileManager.default
        .contentsOfDirectory(at: desktop,
            includingPropertiesForKeys: nil))
        ?.filter { $0.pathExtension == "html" }
        .map { HTMLFile(url: $0) }
        ?? []
}
Key Principle: Write code that tells a story. The function above is self-documenting — its name, parameters, and return type explain exactly what it does without a single comment.

The SwiftUI Revolution

SwiftUI transformed how macOS apps are built by letting developers describe what the UI should look like, not how to construct it. Declarative UI means less code, fewer bugs, and easier iteration.

The @Published property wrapper and ObservableObject protocol create a reactive data flow — when data changes, the UI updates automatically. This is the magic behind this very app.
